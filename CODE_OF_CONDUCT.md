# Code of Conduct

Cortico follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the repository's issues, pull requests and review comments, and wherever someone
represents the project.

Report unacceptable behavior to phantivia@gmail.com. The report stays between you and the
maintainer.
